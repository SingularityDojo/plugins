# report — テーマの振り返り

今日の日付ディレクトリにあるテーマ1つについて、何をして何を学んだかを `report.md` に書き、GitHub に push する。

## 手順

### 1. テーマのディレクトリを決める

- 今日の日付ディレクトリは `~/playground/$(date +%Y/%Y%m/%Y%m%d)`
- その中のテーマのディレクトリから、会話の流れで今終わったテーマを選ぶ。分からないときは一覧を見せて聞く

### 2. plan.md を読む

テーマのディレクトリの `plan.md`（`plan-md` スキルが作ったもの）をいちばんの材料にする。

- ゴール・完了条件 → 何をしたか
- 時間の記録の最初と最後の時刻 → かかった時間
- 気づいたこと・時間の記録のメモ → 学んだこと

plan.md がなければ、会話から書く。

### 3. report.md を書く

```markdown
# <テーマ名>

## 何をしたか

<開始の時刻> 〜 <終わりの時刻>（<分>分）

<何をしたかを2〜3文で>

## 学んだこと

- <学んだこと>
- <学んだこと>

## 次にやりたいこと

- <あれば>
```

- やったことだけを書く。項目を埋めるために話を作らない
- 「次にやりたいこと」がなければ、その見出しごと消す
- 書いたら、中身を短く見せる

### 4. plan.md を締める

時間の記録の最後が「完了」の行でなければ、`date '+%Y-%m-%d %H:%M'` で時刻を取って「完了」の行を足す。

### 5. commit して push する

```bash
cd ~/playground
git add <テーマのディレクトリ>
git commit -m "report: <テーマ名>"
git push
```

- `git add` はテーマのディレクトリだけにする。ほかの変更を巻き込まないため
- push でエラーになったら、エラーの文をそのまま見せて、何が起きているか説明する
